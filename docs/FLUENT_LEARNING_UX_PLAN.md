## Phase 14 — 冷启首页 + 首启体验（立刻做）

**问题**：`lib/main.dart` 里 `home: const MainShell(initialIndex: 1)`，冷启落在媒体库。

**要做**：
1. 将 `MainShell(initialIndex: 1)` 改为 `initialIndex: 0`（或直接 `const MainShell()`，默认已是 0）
2. 全文搜索是否还有别处强制切到库 Tab 作为默认
3. 首页空态（无单元、无最近播放）：标题 + 两行说明 + 主按钮「新建学习单元」+ 次按钮「去媒体库导入」
4. 若本地已有媒体但无单元：主按钮改为「从媒体库生成学习单元」引导

**不改**：Tab 顺序、播放逻辑。

**验收**：冷启必到首页；空态可点；`flutter analyze` 无新 error；commit `Phase 14: ...` 并 push。

## Phase 15 — 首页 × 学习单元加深

**要做**：
1. 首页「继续学习」：取最近未完成单元或上次播放关联单元，一键进执行页/继续播
2. 推荐卡：理由一行必显；点击进单元详情；长按/菜单可忽略（可选）
3. 单元执行页：未完成项排序置顶；完成动画/页内成功条（禁新悬浮 toast）
4. 从日历 due 点进单元后返回日历保持日期

**验收**：有进行中单元时首页 1 动能继续；推荐非空壳。

## Phase 16 — 库 / 选片 / 中心体验

**要做**：
1. 媒体库与 Picker 空态/搜索无结果文案统一风格
2. 中心 Tab：三中心入口卡片显示队列摘要数字（进行中/失败）
3. 处理中心：失败项「重试」可达；成功项可跳转结果（若已有路径则接线）
4. 关键路径（入队、保存单元、开始下载）优先按钮态/页内横幅，收敛新增 `app_toast`（旧路径能改则改，不追求一次清完）
5. 库多选与 Shell 底栏：确认仅一种底栏可见（复用 Phase 8 成果，修回归）

**验收**：中心一眼看到忙闲；关键成功无新悬浮通知。

**状态（实现中）**：空态组件 `MediaLibraryEmptyState`；Centers 大厅徽章；处理中心重试/查看结果；试用选片降级到 AppBar 菜单；CollectionScreen 同步 `librarySelectionActive`。
